# روندي — نظام إدارة مصنع السيراميك والبورسلين

نظام واحد بيربط الإنتاج والجودة والمخازن والصيانة والطاقة والمبيعات والتكلفة. الشاشات عربي من اليمين للشمال، وبتشتغل على الكمبيوتر والتابلت والموبايل.

> الخطة الكاملة والتصميم: [`docs/plan.html`](docs/plan.html)

## المراحل

| المرحلة | المحتوى | الحالة |
|---|---|---|
| ١ | المستخدمين والصلاحيات، والبيانات الأساسية (الموديلات، المقاسات، الأصناف، درجات اللون، العيارات، الخامات، الخطوط، المعدات، الورديات) | ✅ خلصت |
| ٢ | الإنتاج والجودة والفرز | ⏳ |
| ٣ | مخزن الخامات، ومخزن المنتج التام بالتشغيلات والأكواد | ⏳ |
| ٤ | الصيانة والطاقة | ⏳ |
| ٥ | المبيعات والموزعين والشحن | ⏳ |
| ٦ | تخطيط الإنتاج وحساب التكلفة | ⏳ |
| ٧ | لوحة الإدارة العليا والتقارير والتنبيهات | ⏳ |
| ٨ | التسليم: مراجعة أمان نهائية، دليل استخدام مصوّر، شرح التشغيل | ⏳ |

## التشغيل على سيرفر المصنع

المطلوب: جهاز لينكس عليه Docker. كل حاجة بتشتغل بأمر واحد.

```bash
cd deploy
cp .env.example .env        # واملا القيم (الشرح جوه الملف)
docker compose up -d --build
```

بعدها افتح `https://<اسم السيرفر>` من أي جهاز على شبكة المصنع، وادخل بـ `admin` وكلمة السر اللي كتبتها في `SEED_ADMIN_PASSWORD` (هيطلب منك تغيرها على طول). بعد أول تشغيل ناجح خلي `RUN_SEED=false`.

الحاجات اللي لازم تتحفظ برا السيرفر (ورقة في خزنة أو مدير كلمات سر):
- `DATA_ENCRYPTION_KEY`: من غيره أرقام الموبايل وأسرار الرمز الإضافي مش هتتفك.
- `BACKUP_PASSPHRASE`: من غيره النسخ الاحتياطية مش هتترجع.

### النسخ الاحتياطي
- تلقائي كل يوم الساعة ٢ بالليل، متشفر، وبيتحفظ ٣٠ يوم في `deploy/backups`.
- لو حددت `BACKUP_OFFSITE_DIR` (فولدر على جهاز تاني أو هارد خارجي)، بتتعمل نسخة تانية هناك.
- نسخة فورية: `docker compose exec backup backup.sh`
- تجربة الاسترجاع (مستحسن مرة كل شهر) في قاعدة بيانات منفصلة:
  `docker compose exec backup restore.sh /backups/<اسم الملف> rondi_restore_test`

## للمبرمجين

### الأدوات
| الجزء | الأداة |
|---|---|
| الشاشات | Next.js 16 + React 19 + TypeScript + Tailwind CSS 4 |
| الخادم | NestJS 12 + TypeScript |
| قاعدة البيانات | PostgreSQL 16 عن طريق Prisma 7 |
| القواعد المشتركة | `packages/shared`: الصلاحيات، وقواعد فحص كل خانة (zod)، وحسابات التعبئة |
| الاختبارات | Jest (الخادم والقواعد) + Playwright (الشاشات) |

### التشغيل على جهازك
```bash
pnpm install
cp apps/api/.env.example apps/api/.env   # واملا القيم (للتجربة: SEED_DEMO=true)
pnpm db:migrate && pnpm db:seed
pnpm dev                                 # الشاشات على 3000 والخادم على 4000
```

حسابات التجربة (لما `SEED_DEMO=true`)، كلها بكلمة السر اللي في `SEED_DEMO_PASSWORD`:

| اسم الدخول | الدور |
|---|---|
| `admin` | مدير النظام (كلمة سره من `SEED_ADMIN_PASSWORD`) |
| `factory.mgr` | مدير المصنع |
| `prod.mgr` | مدير الإنتاج |
| `sup.a` / `sup.b` / `sup.c` | مشرفين الورديات |
| `quality` | مسؤول الجودة |
| `store` | أمين المخزن |
| `maint` | مسؤول الصيانة |
| `sales` | المبيعات |
| `accounts` | الحسابات |
| `ceo` | الإدارة العليا |

### الاختبارات
```bash
pnpm test        # القواعد المشتركة + الخادم (محتاج PostgreSQL وقاعدة rondi_test)
pnpm test:e2e    # الشاشات من المتصفح (محتاج الخادم والشاشات شغالين على بيانات تجريبية)
pnpm audit:deps  # فحص المكتبات ضد الثغرات المعروفة
```

### قواعد ثابتة في الكود
- **مفيش مسح نهائي**: في trigger في قاعدة البيانات بيرفض أي `DELETE`، والتطبيق نفسه بيتصل بمستخدم ممنوع من المسح. البديل: `isActive = false`.
- **كل تعديل بيتسجل** في `audit_log` جوه نفس الـ transaction بالقيمة القديمة والجديدة. السجل نفسه append-only ومربوط بسلسلة بصمات (`rondi_audit_verify()`).
- **الصلاحيات على الخادم**: كل endpoint عليه `@RequirePermissions(...)`، والشاشة بتخفي الزرار للراحة بس.
- **قواعد الفحص واحدة**: نفس schema من `packages/shared` بيتفحص بيها في الشاشة وفي الخادم.
- **optimistic locking**: أي تعديل لازم يبعت `version`، ولو حد سبقه بيرجع `409 STALE_VERSION`.
- **مفيش أسرار في الكود**: كل حاجة من متغيرات البيئة، والخادم مش بيشتغل لو إعداد ناقص.

### شكل المشروع
```
apps/api        الخادم (NestJS) + prisma/ (الجداول والترحيل والبيانات التجريبية) + test/
apps/web        الشاشات (Next.js) + e2e/
packages/shared القواعد المشتركة بين الاتنين
deploy/         ملفات التشغيل على السيرفر والنسخ الاحتياطي
docs/           الخطة وتقارير مراجعة الأمان
```
